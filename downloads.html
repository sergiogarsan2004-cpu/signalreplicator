Download SignalReplicator

The download is free. To let it trade you need a license key, which you get when you subscribe to any of the plans.

Windows · installer macOS · .dmg

MetaTrader 5 runs on Windows. On macOS the app installs fine, but you still need MetaTrader 5 running on the same machine.

What it installs

A single file. The installer sets up both parts you need:

  • The app, which reads the signals from the Telegram channel.
  • The Expert Advisor for MetaTrader 5, which places the orders. It copies itself into every MT5 installation it finds on the machine.

Getting started

  1. Run the file you just downloaded.
  2. Open MetaTrader 5 and enable algorithmic trading.
  3. Drag the TelegramSignalEA Expert Advisor onto any chart.
  4. Open SignalReplicator and paste your license key.
  5. Pick the channel, the symbol and your risk. Nothing is switched on by default.

The license binds to the machine you activate it on. If you change computer or reinstall Windows, it moves over on its own after 72 hours.
